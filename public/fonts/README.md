# Fonts

`Amiri-Regular.ttf` — Amiri by the Amiri Project Authors (https://github.com/aliftype/amiri),
licensed under the SIL Open Font License 1.1 (`Amiri-OFL.txt`). Downloaded from Google Fonts
(`ofl/amiri`). Used by the PDF report for text the built-in Helvetica cannot show (e.g. Arabic
patient names); it is fetched only when a report needs it.

`NotoSans-Regular.ttf` — Noto Sans by the Noto Project Authors
(https://github.com/notofonts/latin-greek-cyrillic), licensed under the SIL Open Font License 1.1
(`NotoSans-OFL.txt`). Used by the PDF report for Greek letters in statistics (η², χ², α) and other
non-Latin, left-to-right text; it is fetched only when a report needs it. It has no ≥ ≤ → ≈ √,
so the report spells those out.
